# Photographer Portfolio

My own photography portfolio, which I both **designed** and **developed** from scratch.

## Quick Start

### Requirements

- Node.js >= 22
- npm >= 10

### Setup

1. **Install dependencies:**

    ```bash
    npx pnpm install
    ```

2. **Configure environment:**

    ```bash
    cp .env.example .env
    ```

3. **Start development:**
    ```bash
    npx pnpm run dev
    ```

## Storyblok

### Login

```bash
npx pnpm storyblok login
```

### Logout

```bash
npx pnpm storyblok logout
```

### Types

```bash
npx pnpm sb-types
```
